# CardCatch – Core API (v1.0 Stable)

This is the FastAPI backend powering CardCatch's live card price fetching.

## Features
- eBay OAuth authentication
- /price and /bulk-price endpoints
- Supports card name, set, number, condition, grading, etc.
- Outputs median pricing, count, and suggested resale value
